🔥 Deka Sir Classes — Firebase Migration Tool

One-time use. Pulls everything from Google Sheets and writes it into Firestore. Does not touch or modify your live Sheets data — read-only on that side.

⚠️ Run this only once with fresh/empty Firestore collections. Running it twice will create duplicate documents. If you need to re-run after fixing something, clear the Firestore collections first (I'll tell you how if that comes up).
